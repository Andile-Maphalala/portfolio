Resource Tracker

A full-stack resource and inventory planning tool for gamers managing complex build requirements — crafting trees, facility needs, and component tracking for games like Subnautica, Valheim, and Grounded. Built to go deeper on Blazor WebAssembly and to practice clean/hexagonal architecture end-to-end on a project built from scratch.

Architecture: Frontend and backend are intentionally split into separate repos to allow independent deployment and versioning. Backend uses a layered/clean architecture (Domain, Application, Persistence, Api) with CQRS pattern and image handling isolated in its own service; integration tested with Testcontainers.
